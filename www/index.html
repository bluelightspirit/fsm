    How to use

    • Create a new FSM from a regex: in Automaton properties, enter a Python-style regex under Regex → automaton, choose ε-NFA or DFA, then select Create as new FSM. See regular expression notes for syntax.
    • Alternative regex converter: CyberZHG's nfa2dfa is a useful alternative if you run into issues with the regex converter here
    • Add a state: double-click on the canvas
    • Add an arrow: Shift-drag from one state to another, or Shift-click the source and click the destination
    • Select something: click it once
    • Move something: drag it around
    • Select a thin line: Ctrl+click it (Cmd+click on Mac) for a wider hit area
    • Adjust a curve: select its arrow to show three curve handles; move the last handle to the page fragment where the arrowhead should land
    • Move an arrow's label: select the arrow, then alt-drag (alt-double-click resets it)
    • Clear selection: press Escape
    • Rename: click a state or arrow and type, or use the list below the canvas
    • Finish typing: press Enter, then drag the selected state to move it; press Enter again to resume label typing
    • Continue on a new line: press Shift+Enter while typing
    • Delete something: select it, press Delete or Cmd/Ctrl+⌫
    • Make accept state: double-click an existing state
    • Subscript: s_1 subscripts one character, s_1_2 chains into one subscript, and s_{12} keeps grouped subscripts intact. Use \_ for a literal underscore.
    • Greek letters: \alpha, \Sigma, ... (also inside subscripts, e.g. s_\alpha)
    • Cheat sheets: LaTeX · Typst #1 · Typst #2
    • Official docs: LaTeX · Typst for LaTeX users
    • Label formatting: LaTeX commands such as \textbf{...} and \url{...} are not supported in labels yet. Support and separate Typst/LaTeX label variants are still undecided.
    • Undo / Redo: Cmd/Ctrl+Z · Shift+Cmd/Ctrl+Z

    Automaton properties

    Read the current states and arrows.

    Regex → automaton

    Uses Pyformlang's Python-style regex syntax (for example, | for union, * for zero or more, + for one or more). Creates a separate FSM; Lean can check its structural invariants.

    Convert

    Creates a separate FSM in the left workspace list using subset construction.

    Finite automaton → grammar

    Creates an equivalent right-linear grammar (a regular subset of CFGs) from the current FSM.
    
        
    
        
    Lean checks the current graph's state, transition, determinism, and completeness invariants through PyPantograph. Install both optional integrations with python -m pip install -r requirements.txt. CFG → PDA is the general direction; arbitrary CFGs cannot be converted to finite automata.
